# Artifacts

| Artifact | Responsibility |
|---|---|
| `src/closed_record/core.cljc` | Public API: the `defclosedrecord` macro and `check`. |
| `src/closed_record/runtime.cljc` | Internal protocol `ClosedRecord` (D-17), class-name helper, and public run-time helper `key-error`, which the generated code calls (D-21). No dependency on the public API or emitter. |
| `src/closed_record/impl/jvm.clj` | JVM emitter. Checks the options and builds the type form (`deftype*`, or `value-type.core/defvaluetype*` with `:value-type true`) and the factories. One representation description holds the differences of the two modes. Resolves value-type only in value mode. |
| `test/runtime/closed_record/*_test.clj` | Behaviour, differential, equality, malli, nil, literal and constant tests. `value_type_option_test.clj`: the ordinary part of VT-V1 (expansion fixture, option errors, `:closed-record/value-type-unavailable` with and without cause). A test namespace with shared checks calls `closed-record.checks.support/define-checks` with its check namespace, ordinary record options and representation `:identity`, and keeps its tests that are not shared. |
| `test/runtime/closed_record/checks/*.clj` | Shared checks (`closed-record.checks.<topic>`, one for each test namespace with shared checks): the run-time behaviour tests of a defined type as plain top-level forms, so clj-kondo lints them. No suite loads them. `closed-record.checks.support/define-checks` reads the source of a check namespace and defines its types and tests in the current namespace with the given record options and representation value; the check namespace defines the D-06 serialization test only for identity output. In value mode (placeholder `metadata-and-hidden-keys?` false), the check namespaces do not define the metadata and hidden-key checks (VT-V3): top-level `when` guards, guards inside a test, and in `closed-record.checks.literal` the private macro `if-metadata-and-hidden-keys` for literals read at macro expansion. Loads without value-type. |
| `test/runtime/closed_record/checks/support.clj` | `closed-record.checks.support/define-checks`: the function that defines the checks of a shared check namespace in the current namespace. It takes the check namespace symbol and `{:record-opts [k v …] :representation r}`, and throws if `r` is not `:identity` or `:value`. It reads the check source, evaluates only its `ns` form, then reads the other forms in that namespace. It qualifies the symbols from the check namespace, inserts the record options after each field vector, replaces `$P`, and replaces the placeholder var `closed-record.checks.support/representation` with `r` and the placeholder var `closed-record.checks.support/metadata-and-hidden-keys?` with `false` when `:record-opts` has `:value-type true`, else with `true`. It evaluates each form with the check source as the compiler source file, so the file and the line of a failure both name the check source. |
| `test/runtime/closed_record/form_support.clj` | `closed-record.form-support`: `walk-form`, the form walker that keeps metadata, and `with-options`, which inserts record options after the field vector. The expansion fixture and `closed-record.checks.support` use them. |
| `test/runtime/closed_record/probe_support.clj` | `closed-record.probe-support`: `eval-in-new-ns`, which evaluates a form in a new namespace from `create-ns`, `thrown`, which gives the exception of a call or nil, `data-of`, which gives the `ex-data` of that exception, and `expansion-error`, which gives the exception of a macroexpansion in a given namespace (without the `CompilerException` wrapper) or nil. The `:load-ns` tests of `closed-record.defclosedrecord-test` and `closed-record.value-type.representation-test` use `eval-in-new-ns` and `thrown`; `closed-record.checks.defclosedrecord` uses `thrown` and `data-of`; `closed-record.checks.malli` and `closed-record.checks.hidden-key` use `data-of`; `closed-record.value-type-option-test` (also in the child JVM of its absent-var test) and `closed-record.value-type.clj-1-11-test` use `expansion-error`. |
| `test/runtime/closed_record/expansion_fixture.clj` | `closed-record.expansion-fixture`: the fixture forms, the printed and gensym-normalised expansion (position metadata removed with `closed-record.form-support/walk-form`), and `record!`, which records the fixture again. |
| `test/runtime/closed_record/expansion_fixture.edn` | The recorded ordinary expansions (VT-I2). Record again in the change that changes the ordinary expansion on purpose. |
| `test/runtime/closed_record/subprocess.clj` | `closed-record.subprocess/run`: runs `clojure.main` in a child JVM with the `java` binary, input arguments and class path of the test JVM, plus extra class path entries and JVM options. A child that does not exit in the time limit (default 5 minutes) is destroyed; the result then has a nil `:exit`, `:timed-out` true and the output so far. `temp-dir` creates a temporary directory with a name prefix; `delete-tree` deletes a file or a directory and all of its contents, and does not follow symbolic links. The absent-var test and the AOT test use them and delete their directory in a `finally`. |
| `test/value-type/` | value-type suite (`:value-type-test` alias, Clojure 1.12): the shared checks with `:value-type true`, VT-V2, VT-V4, VT-V5, VT-V6, VT-V7, VT-V9, VT-V11, VT-V12 and the does-not-load part of VT-V1. It does not run V-14 (hidden keys). Requires the property `closed-record.test.representation` (`identity` or `value`). |
| `test/value-type-clj-1.11/` | The Clojure 1.11 part of VT-V1 (`:value-type-test` alias without `:clj-1.12`). |
| `test/runtime/closed_record/compiler_rules_test.clj` | Tests that fix K-06 to K-08 (V-13). |
| `test/runtime/closed_record/checks/hidden_key.clj` | Tests that fix hidden keys of a literal and their retention (V-14). |
| `test/runtime/closed_record/checks/property.clj` | Property test of random `assoc` and `dissoc` sequences (V-03). |
| `test/runtime/closed_record/checks/differential.clj` | Differential property test against `defrecord` after random permitted steps (V-02). |
| `test/runtime/closed_record/checks/malli.clj` | Tests of malli map schemas and transformers on a closed record (V-07). |
| `test/runtime/closed_record/bench_report_test.clj` | Tests of the bench pure layer (`closed-record.bench.report`): per-call stats, pass rule, table and exit code (V-11). No benchmark run. |
| `test/runtime/closed_record/bench_fork_test.clj` | Tests of the bench fork layer (`closed-record.bench.fork`): fork failure causes and parent exit codes with short shell commands in place of child JVMs, the fork numbers of a full run (0 to 4, in start order), the child command against the state of the test JVM, and the run order of each fork (V-11). No benchmark run. |
| `dev/bench/` | `closed_record/bench.clj` (`closed-record.bench`): criterium benchmarks of the six S-03 operations against `defrecord` (V-11), over 5 child JVM forks. The child entry point measures and writes its result to a file. `closed_record/bench/fork.clj` (`closed-record.bench.fork`): the run order of a fork, the child command and the parent, which starts the forks, without criterium. `closed_record/bench/report.clj` (`closed-record.bench.report`): the pure layer (per-call stats, encode and decode of the child result, statistics over forks, pass rule, table, exit code), without criterium. `closed_record/bench/value_type.clj` (`closed-record.bench.value-type`): VT-V8, `hash` and `=` of value-type and ordinary records, its own forks and table; no other namespace requires it. `closed_record/bench/value_class.clj` (`closed-record.bench.value-class`): `value-class?` (reflective `Class.isValue`), without dependencies; `closed-record.bench.value-type` and `closed-record.value-type.expectation` use it. `timing/run.sh` reads `BENCH_ALIASES` and `BENCH_JVM_OPTS`. |
| `build.clj` | Maintainer build: validates the Git version, clears stale output, and packages runtime source, Maven metadata, and the license in one source-only library JAR. `clean` removes build output without Git metadata. |
| `bb.edn` | Shared formatting, dependency lint setup, lint, Vale, API generation/freshness, and staged-content hook tasks; `lychee:check` invokes the link-check helper. |
| `dev/link_check.clj` | Selects Git-tracked Markdown and runs local fragment and online link checks with lychee. Both passes run; either failure fails the task. |
| `lychee.toml` | Shared local and CI link policy: verified TLS, bounded requests and retries, successful HTTP statuses, and no cache or report writes. |
| `dev/link_check_test.clj` | Real-process contract tests with temporary Git repositories and a loopback HTTP server. Checks selection, links, diagnostics, failure propagation, and unchanged checkout files. |
| `.github/workflows/ci.yml` | Read-only CI orchestration: pinned tool setup, shared formatting and lint, Vale, API freshness, focused tooling tests, three alias-based runtime test entries, the jobs `Value-type tests (Temurin 21)` and `Value-type tests (Valhalla)` (a SHA-256-checked, cached early-access JDK), separate full-history build verification, structured test-failure uploads, and a separate Markdown links job that runs contract fixtures then `bb lychee:check`. No benchmarks or publication. |
| `LICENSE` | Complete EPL-2.0 license text for the repository and the JAR root. |
| `test/build/build_test.clj` | Separate build tests: version validation, missing-Git failure, repeatable clean, artifact contents and metadata, stale-output removal, and an isolated consumer JVM. Uses real processes and temporary project fixtures. |
| `deps.edn` | Clojure 1.11 runtime dependency. Maintainer aliases `:build` and `:build-test` supply tools.build; `:build` selects the `build` namespace, and `:build-test` adds the repository root and `test/build` paths for use with `:test`. The `:quickdoc` alias supplies Quickdoc and `dev/quality` for API generation. The `:tooling-test` alias supplies scry and the `dev/quality` and `test/tooling` paths for quality-tool tests. Other aliases `:test`, `:bench`, `:nrepl`, `:clj-1.12` and `:clj-1.13`. The `:test` alias has scry, `test.check` and malli (`metosin/malli`), and the path `dev/bench` for the bench report and fork layer tests. The `:bench` alias has criterium (`org.hugoduncan/criterium` 0.5.251-ALPHA). The `:value-type-test` alias has value-type (`org.hugoduncan/value-type` at a pinned Git SHA) and the paths `test/value-type` and `test/value-type-clj-1.11`. The base `:deps` do not have value-type. The `:enable-preview` alias adds the JVM options `--enable-preview` and `--add-exports=java.base/jdk.internal.value=ALL-UNNAMED` (for `value-type.array`), for a Valhalla early-access JDK. |
