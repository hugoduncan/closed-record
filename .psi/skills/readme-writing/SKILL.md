A readme is the portal into the project.  It is written for somebody
coming to the project. It should help them understand what problem the
project is trying to solve, the approach to solving it, and how to get
started.

## Content

It should contain:
  - a description of the problem that the project aims to solve
  - a description of its approach to solving the problem
  - an AI usage disclaimer
  - a statement on the maturity of the project, and its usability and stability
  - installation instructions
  - basic usage instructions

Defer to API docs for fine grained details.

It should not contain:
  - internal details irrelevant to the use of the project

## Style

Be precise and concise.

Do not use superlatives or self promoting language.
